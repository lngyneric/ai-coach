🎨 主题定制

通过 6 个 CSS 变量 + 3 处文案，快速切换企业品牌

:root {
--brand-name: "AI-Coach"; /* 品牌名称 */
--brand-color: #0f63ee; /* 品牌主色 */
--brand-gradient: #3e84f4; /* 渐变辅色 */
--logo-text: "S"; /* Logo 文字 */
--custom-domain: "ai-coach.sysmex.com.cn";
--portal-hero-title: "数智化企业培训";
--portal-vision: "..."; /* 愿景文案 */
}

🌐 自定义域名

将企业大学部署到自有域名下

nginx 配置

server {
  listen 443 ssl;
  server_name ai-coach.sysmex.com.cn;
  root /usr/share/nginx/html;
  index portal.html;
  location / { try_files $uri $uri/ /portal.html; }
}

DNS 解析

将域名 CNAME 或 A 记录指向服务器 IP。支持 Let's Encrypt 自动签发 SSL 证书。
